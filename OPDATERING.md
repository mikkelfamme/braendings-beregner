# Opdatering til Brændings Beregner 8.0

1. Udpak ZIP-filen.
2. Åbn mappen `GitHub-upload`.
3. I GitHub: Code -> Add file -> Upload files.
4. Upload indholdet af `GitHub-upload` oven på de eksisterende filer.
5. Commit fx som `Opdater til Brændings Beregner 8`.
6. Gå til Actions -> Udgiv Braending og vent på grøn build + deploy.
7. Genindlæs appen på iPhone. Hvis den er gemt på hjemmeskærmen, luk appen helt og åbn den igen.

## Ændret i 8.0
- Elprisdiagrammet vises nu kun på fanen `Beregn`, som er forsiden.
- Den lange engelske attributionstekst er fjernet. Af licenshensyn vises i stedet den korte, klikbare tekst `Elprisdata fra Strømligning` tæt ved prisdata.
- Teksten om automatisk prisberegning under overskriften på Beregn er fjernet.
- Teksten `Fast metode: 7,0 kW ...` under programvalg er fjernet.
- Introen `Hvornår skal ovnen starte?` på fanen Billigst er fjernet.
- Sætningen om separat alternativ mellem 06.30 og 21.30 er fjernet.
- Dagsfunktionen viser nu fx `Hvornår er det billigst 26.09?` uden ordet `den`.
- Versionen er opdateret til 8.0.0.

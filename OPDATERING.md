# Brændings Beregner 10.0

## Nyheder

- Alle programvalg starter nu på **P1**.
- **Elprisen** viser tre hurtige nøgletal: pris nu, billigst i dag og dyrest i dag.
- Prognosepriser er visuelt adskilt fra offentliggjorte priser i søjlediagrammet.
- **Beregn** sammenligner den valgte start med dagens billigste start mellem 06.30 og 21.30 og viser potentiel besparelse.
- **Billigst** er forenklet til to valg: **Næste 3 døgn** eller **Vælg en dag**.
- Resultater under Billigst viser også, hvor meget der maksimalt kan spares mellem billigste og dyreste mulige start i søgevinduet.

Appen er fortsat bevidst lille: Elprisen → Beregn → Billigst → Keramik ovnen.

# Brændings Beregner

Mobilvenlig GitHub Pages-app til Cerama SC 100 med Strømligning-priser, brændingsberegning og optimering af starttidspunkt.

Version 10.0.0.

## Navigation

**Elprisen → Beregn → Billigst → Keramik ovnen**

- Elprisen viser timepriser, dagens billigste/dyreste time samt forskel på offentliggjorte priser og prognoser.
- Beregn beregner en konkret brænding og sammenligner med dagens billigste praktiske start.
- Billigst kan enten søge de næste 3 døgn eller en valgt dato.
- Keramik ovnen indeholder metode, fabriksprogrammer og status for prisforbindelsen.

Alle programvælgere starter på P1.
